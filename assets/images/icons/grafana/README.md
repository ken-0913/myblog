# Grafana 아이콘

Grafana 는 CNCF 프로젝트가 아니라 Grafana Labs 제품이라 `../cncf/` 와 분리했다.

- `grafana-icon.svg`: [grafana/grafana](https://github.com/grafana/grafana) 저장소의 `public/img/grafana_icon.svg` (Grafana 앱이 실제로 쓰는 아이콘)

Grafana 로고는 Grafana Labs 상표다([brand guidelines](https://grafana.com/legal/trademark-policy/)). 기술 설명과 다이어그램에서 Grafana 를 가리키는 용도로만 쓰고, 색과 모양을 바꾸지 않는다.
