{{- /* 목록 페이지(카테고리·태그·/posts/)의 연도 그룹 안에서 글을 series 로 한 번 더 묶는다. - 입력: dict "Groups" .Paginator.PageGroups "DateFormat" "01-02" - series(front matter `series: ["MLPE 1주차"]`)가 있는 글은 연도 아래 series 소제목(시리즈 페이지 링크) 밑에, 없는 글은 연도 바로 아래에 둔다. series 순서는 연도 안에서 처음 나오는 순서(= 최신 글 순)다. - 테마의 term.html / section.html 을 덮어쓴 layouts/term.html, layouts/section.html 이 호출한다. - 소제목 스타일은 assets/css/_custom.scss 의 .archive .group-subtitle, .archive-series */ -}} {{- $fmt := .DateFormat -}} {{- range .Groups -}}

{{- with $seriesPage -}}{{ $s }}{{- else -}}{{ $s }}{{- end -}}

{{- range $pages -}} {{- if and .Params.series (eq (index .Params.series 0) $s) -}}
{{- .Title -}} {{- .Date.Format $fmt -}}
{{- end -}} {{- end -}}
{{- end -}} {{- range $pages -}} {{- if not .Params.series -}}
{{- .Title -}} {{- .Date.Format $fmt -}}
{{- end -}} {{- end -}} {{- end -}}
